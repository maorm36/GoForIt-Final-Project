## About GoForIt

**GoForIt** is a B.Sc. Software Engineering final project designed to encourage students to increase their daily physical activity through walking.

The Android application combines continuous activity tracking with competitive, motivational, and campus-oriented features.

### Main Features

* Continuous step counting
* Daily and competitive leaderboards
* Personal walking challenges
* Campus step verification
* Personalized walking routes
* BLE-based bonus stations
* Step history and statistics
* Anti-cheat and data-integrity mechanisms
* Firebase-based backend services
